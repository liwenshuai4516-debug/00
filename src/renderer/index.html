自定义供应商

        
配置文件：

        
在文本编辑器中保存配置，然后重新读取。认证沿用 Pi 的环境变量、auth.json 或 models.json，不在页面回填密钥。

        

          
          
        

        

          兼容接口配置示例
          
{
  "providers": {
    "my-provider": {
      "baseUrl": "https://api.example.com/v1",
      "api": "openai-completions",
      "apiKey": "$MY_API_KEY",
      "models": [{ "id": "my-model" }]
    }
  }
}

          
将地址、模型编号和环境变量名替换为实际值。models.json 同样支持 headers、modelOverrides 等官方字段。Provider 扩展放入 Pi 资源目录，修改后在聊天中执行 /reload。
