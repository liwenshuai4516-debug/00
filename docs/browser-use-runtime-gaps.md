# browser-use 正式接入前的运行时缺口

核对日期：2026-11-06，Asia/Shanghai。对象为 requirements.lock 中的 browser-use 0.13.14 及已提交探针；PyPI 元数据只读查询显示该版本仍是最新版。本文记录已确认的兼容性边界和待决策事项，不表示依赖已经修改或正式入口已经接入。

## 本轮结论

受控功能验证已成功，记录见 [验证报告](browser-use-smoke.md)。公开接口没有提供关闭本地启动重试、自动重连或默认逐步截图的参数。继续在这个版本上尝试不同参数或注册事后停止回调，无法证明满足仓库首次异常停止和最小采集要求。

本轮没有启动浏览器、请求模型、改动安装包或更换依赖。没有重新运行已经通过的场景，也没有产生新的模型费用。

## 公开接口与实现依据

以下位置均相对已安装包的 browser_use/，行号针对锁定版本；仅用于解释实现事实，运行时代码不深层导入这些内部方法。

| 拟议公开能力 | 探针所需行为 | 必要验证 |
