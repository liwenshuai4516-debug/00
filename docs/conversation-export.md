# 对话导出

页面头部的导出按钮触发主进程保存对话框，导出当前会话的**展示文本快照**；不导出内部字段、原始工具结果或未展示的思考内容。

## 格式

保存文件名决定格式：

| 扩展名 | 内容 |
| --- | --- |
| `.txt`（默认） | 纯文本，按 `【我】`/`【Agent】` 等角色分段 |
| `.md` | Markdown，角色为二级标题，保留原文换行 |
| `.json` | 结构化对象：`exportedAt`、`sessionId`、`workspaceDir`、`model`、`messages[{role,text}]` |

JSON 只包含展示用字段，不包含 `internalData` 等内部数据；未知扩展名按 `.txt` 处理。

## 行为

- 取消保存不写文件；写入成功后才报告导出完成，失败透传错误。
- 导出期间占用互斥入口，拒绝新建、整理等冲突操作；生成中拒绝导出。
- 正文与目标路径都由主进程决定，页面不能伪造。

## 验证

- `tests/unit/conversation-export.test.js`：txt 中文/换行、取消不写入、写入失败透传、生成中拒绝与互斥入口、Markdown 标题结构与 JSON 字段过滤。
