## 本次整体链路

1. **工具准备**：接入 Playwright Test MCP 1.64.1，验证握手与工具目录。目录列出 92 个工具，但不以数量证明所有工具可调用；其中登录态专用接口实际不可调用，后续使用公开 `BrowserContext.storageState()` 完成已授权的临时导出。
2. **启动录制**：调用 `generator_setup_page`，使用显式 CommonJS seed。最初默认 TypeScript seed 不符合 `.spec.cjs` 匹配规则，改用显式 seed 后成功，保留早期错误。
3. **登录交接**：访问目标地址被重定向到登录页。用户在可见 Chromium 中手动登录；该阶段关闭 trace。登录后核对页面显示的管理员角色，未在聊天中收集密码。
4. **功能录制**：通过实际快照定位元素，录制名称/编号查询、详情与返回、空结果与重置、部门及流程节点筛选，保存原生请求/响应、快照和截图。
5. **用例形成**：调用 `generator_read_log`、`generator_write_test`，形成一个包含 6 个 `test` 的 CommonJS 文件。最终定位器使用真实观察到的 role、名称和选择器容器，不保留临时 ref 或动态生成 id。测试数据通过外部 JSON 提供。
6. **独立回放**：用户单独授权临时保存登录态。在新浏览器上下文中使用官方 CLI 执行，单 worker、零重试；约 17.48 秒，退出码为 1。
7. **结果整理**：读取原生 `results.json`，生成汇总和用例说明，保留 HTML 报告、截图与 trace；将脚本摘要与实际执行版本核对。
8. **结束清理**：临时登录态删除，录制页面重置并关闭；服务端业务数据未创建或修改。

本次由外部助手直接连接已配置的测试 MCP，并组织脚本、回放和报告；没有调用项目的 `qa_ui_prepare`。录制窗口在独立回放期间仍保留，回放后才关闭，这也不同于项目技能要求的“先关闭录制页面，再正式回放”。

两条链路都由 Agent 选择场景、依据日志整理操作代码并编写断言。MCP 提供页面操作、日志和文件写入接口；`generator_write_test` 接收 Agent 提供的代码，不负责自行推导业务预期。

## 本轮项目检查与问题

### 1. 最新单 case 闭环专项检查通过，早期路径失败已修复

首次运行 `node --test tests/unit/ui-testing-runtime.test.js` 时，资源登记和已有 case 回放通过，录制在 `generator_write_test` 调用中返回：

```text
Error: Test file did not match any of the test dirs: qa/ui/cases
```

比对期间项目提交 `fabcf4d` 补充了相对路径 `caseFileName`，并同步技能与检查脚本。绝对 `caseFile` 继续用于读取和交付，相对 `caseFileName` 用于官方写文件工具。

随后对最新源码重新执行同一专项检查：**3 通过、0 失败、0 跳过，约 8.60 秒，退出码 0**。录制场景实际完成环境准备、真实 SDK 工具发现、setup、点击、日志读取与钩子保存、脚本写入、页面关闭及 CLI 回放。已有 case 检查还覆盖故意断言失败时的原生失败报告和截图，不把该受控失败当成专项检查失败。

早期失败和最新通过的记录分别保留，当前结论使用最新结果。该路径问题属于测试宿主接入，和本次外部业务的流程节点筛选失败无关。

### 2. 带登录场景缺少本次所用的正式入口

`qa_ui_prepare` 未提供可见录制、私有登录态输入或登录态清理字段，MCP 固定以 headless 启动；回放配置也没有 storageState 交接。本次需要的手动登录和已授权临时登录态复用由外部助手额外完成。应优先补齐实际需要的这一条路径，而不是引入另一套账号管理或安装旧版 Pi 工作流。

### 3. 旧命令入口仍失效

`package.json` 仍声明 `ui:case` 指向 `scripts/run-ui-case.cjs`，但该文件不存在。实际执行旧命令返回 `MODULE_NOT_FOUND`。这是旧入口残留，不代表新的 `qa_ui_prepare` 和内置 CLI 回放同样失效；新回放路径已单独检查通过。

### 4. 比对过程中发现的重复登记已移除

早期工作区快照同时注册 `ui-testing` 与 `desktop-ui-testing`，真实资源加载器返回 `qa_ui_prepare` 工具冲突。比对期间其他工作区改动移除了重复工厂；最新资源专项检查通过，**该项不再列为当前待修问题**。历史诊断保留在本机比对记录中。
